# EduPredict — Big Data + Predictive Analytics for Education

A Big Data project that helps education institutions improve student retention, allocate resources better, and personalize learning. It uses **Hadoop / HDFS** for storage, **Spark** for processing, **Kafka** for real-time streams, **MongoDB** for live app data, **machine-learning models** for predictions (performance, dropout risk, course demand), and **Tableau** for dashboards.
